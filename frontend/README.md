# Frontend de facturación electrónica

Angular 22 con PrimeNG. Cómo correrlo y probarlo: ver el [README principal](../README.md).

- `src/app/core`: autenticación (servicio, interceptor, guards, login) y layout.
- `src/app/shared`: validadores, pipes y componentes reutilizables.
- `src/app/features`: una carpeta por módulo, cada una con sus rutas en carga diferida.
